# TM1637

Ce module pilote un afficheur 7 segments 4 digits base sur TM1637.

## Fiche rapide

- Plateforme: MicroPython / Raspberry Pi Pico
- Interface: bus TM1637 a 2 fils
- Dependances: `machine`, `micropython`, `time`

## Pinout

| Signal | Pico |
|---|---|
| CLK | A definir |
| DIO | A definir |

## Fonctions principales

| Fonction | Parametres | Description |
|---|---|---|
| `TM1637(clk, dio, brightness=7)` | `clk`: broche horloge, `dio`: broche donnees, `brightness`: luminosite de `0` a `7` | Initialise l'afficheur TM1637. |
| `brightness(val=None)` | `val`: nouvelle luminosite ou `None` pour lire la valeur actuelle | Lit ou regle la luminosite. |
| `write(segments, pos=0)` | `segments`: tableau de segments, `pos`: position de depart | Ecrit des segments bruts sur l'afficheur. |
| `encode_digit(digit)` | `digit`: valeur de `0` a `15` | Convertit un chiffre hexadecimale en segment. |
| `encode_string(string)` | `string`: texte a encoder | Convertit une chaine en segments TM1637. |
| `encode_char(char)` | `char`: caractere a encoder | Convertit un caractere unique en segment. |
| `hex(val)` | `val`: valeur hexadecimale | Affiche une valeur hexadecimale sur 4 digits. |
| `number(num)` | `num`: entier a afficher | Affiche un nombre entier aligne a droite. |
| `numbers(num1, num2, colon=True)` | `num1`, `num2`: deux nombres, `colon`: active ou non les deux-points | Affiche deux nombres sur 2 digits chacun. |
| `temperature(num)` | `num`: temperature a afficher | Formate un affichage temperature avec symbole degre. |
| `show(string, colon=False)` | `string`: texte court, `colon`: active ou non les deux-points | Affiche une chaine jusqu'a 4 caracteres. |
| `scroll(string, delay=250)` | `string`: texte a faire defiler, `delay`: temporisation en ms | Fait defiler un texte sur l'afficheur. |

## Remarques

- Le driver est base sur une implementation MicroPython connue (licence MIT incluse dans le fichier).
- Une version `TM1637Decimal` gere les points decimaux.
