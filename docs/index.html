Bienvenue sur la bibliotheque EPHEC

Cette page vous aide a comprendre comment parcourir le site, recuperer un module et l'utiliser dans vos projets MicroPython.

Page d'accueil

Comment utiliser le site

  1. Choisissez une categorie dans la barre laterale.
  2. Ouvrez un module pour lire sa fiche rapide et sa documentation.
  3. Copiez le code du module ou de l'exemple dans votre projet MicroPython.
  4. Adaptez les broches GPIO selon votre cablage reel.

Ce que vous trouverez ici

  • Une documentation courte en francais pour chaque module.
  • Le code source complet consultable directement dans le navigateur.
  • Des exemples d'utilisation pour les modules qui en disposent.

Conseil de demarrage

Commencez par un module simple, verifiez le cablage, puis executez un exemple minimal avant d'integrer le composant dans un projet plus grand.

Exemple de structure de projet

Base minimale pour reutiliser un module de la bibliotheque.

from machine import Pin

# Exemple generique: remplacez l'import par le module choisi.
from servo import ServoMotor

servo = ServoMotor(pin_number=15)
servo.set_angle(0)

print("Module charge et pret a l'emploi")
